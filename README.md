# 基于多模态情感分析的智能图像裁剪系统

> 将情感感知引入图像裁剪，让模型理解"好构图"背后的情感逻辑

## 项目简介

本项目提出了一种**基于多模态情感分析的智能图像裁剪系统**。系统通过大语言模型生成**情感描述**作为先验信息，与视觉特征融合，引导模型理解图像构图的美学质量。

### 研究背景

本项目是在论文 **《Image Cropping Guided by Vision-Language Understanding》**（Li Yan, Huiying Zheng*, Rui Yao, Yan Zhang, Jinyue Liu, Hancheng Zhu）的基础上完成的。

#### 原论文结构

原论文提出了视觉-语言引导的图像裁剪框架，其输入包含**两张图**：

- **图像图**：原始输入图像
- **文字图**：大语言模型对图像生成的语义描述

模型通过融合这两张图的信息，辅助裁剪决策。原论文使用通用提示词让大模型描述图像的内容、场景等信息。

#### 本项目的改进

本项目在论文框架的基础上，进行了**两个关键改进**：

**1. 提示词升级：从单纯描述到情感描述**

| 方面 | 论文方法 | 本项目 |
|------|----------|--------|
| **提示词设计** | 通用描述提示词 | **情感感知提示词** |
| **文字图内容** | 描述图像内容、场景 | 描述图像的**情感氛围** |
| **描述维度** | 内容 + 场景 | 内容 + 场景 + **情感** |

**2. 训练策略：将情感单独作为特征**

| 方面 | 论文方法 | 本项目 |
|------|----------|--------|
| **特征维度** | 视觉 + 语义 | 视觉 + **情感** + 语义 |
| **情感建模** | 未涉及 | 将情感作为**独立特征**纳入训练 |
| **训练方式** | 文本描述整体参与训练 | 情感描述**单独提取**并作为独立特征参与训练 |

### 数据来源

本项目的训练和评估数据来源于开源数据集：

- **GAIC (GAICD)**: A Large Database for Image Cropping Quality Assessment
  - 论文: "Reliable and Efficient Aesthetic Assessment of Image Cropping with the GAIC Database"
  - 包含 20K+ 张图像，每张图像有 60+ 个候选裁剪区域及对应的质量评分
  - 数据集链接: [GAICD](https://github.com/HuiZeng/Grid-Anchor-based-Image-Cropping)

### 提示词升级：从单纯描述到情感感知

原论文使用通用提示词生成图像的内容描述，本项目对提示词进行了**升级**，在描述图像内容的基础上，**增加情感描述**：

**原论文提示词（单纯描述）**：
```
请描述这张图片的内容、场景和构图特点。
```

**本项目提示词（情感感知）**：
```
请分析这张图片，包括：
1. 图像内容描述（主体、场景、构图）
2. 情感氛围分析（温馨、宁静、热烈、忧郁等情绪基调）
3. 视觉情感元素（光线、色彩、构图带来的情感体验）
请用简洁的英文描述，重点突出情感特征。
```

通过提示词升级，大模型生成的**文字图**不仅包含内容描述，还包含**情感描述**。

### 情感描述数据生成

本项目使用**千问大模型（Qwen）**，通过升级后的**情感感知提示词**，为数据集中的每张图像自动生成包含情感信息的描述：

生成的情感描述将作为**独立的情感特征**参与模型训练（详见下文训练策略）。

## 核心思想

### 问题定义
给定一张原始图像和多个候选裁剪区域，通过视觉-情感理解预测每个裁剪的构图质量分数，选出最佳裁剪方案。

### 技术路线：双头架构

本项目采用**双头架构**，分别处理图像和情感文本信息：

```
输入图像 ──→ [图像头] ──→ 视觉特征编码 ──┐
                                          ├──→ 多模态情感融合 ──→ 质量评分预测
情感描述 ──→ [情感头] ──→ 情感语义编码 ──┘
```

**图像头（Visual Head）**:
- 使用预训练的视觉编码器（CLIP ViT-B/32 / ResNet-50）
- 提取图像的多尺度视觉特征
- 捕获构图、色彩、纹理等视觉信息

**情感头（Emotion Head）**:
- 使用预训练的文本编码器（CLIP Text Encoder）
- 将千问大模型通过情感感知提示词生成的情感描述编码为语义向量
- 捕获图像的情感氛围、情绪基调、视觉感受等情感信息

**多模态情感融合**:
- 使用 Cross-Attention / Gated Fusion 机制
- 动态融合视觉特征和情感语义特征
- 让模型同时理解"看到什么"和"感受到什么"

### 训练策略：情感作为独立特征

**原论文训练方式**：
- 文字图（文本描述）整体参与训练
- 文本描述作为单一的语义特征与视觉特征融合

**本项目训练策略**：
- 从大模型生成的描述中**单独提取情感信息**
- 将情感作为**独立的特征**参与训练
- 模型同时学习三种特征：
  - **视觉特征**：从图像中提取
  - **语义特征**：从文本描述的内容部分提取
  - **情感特征**：从文本描述的情感部分提取（**独立特征**）

```
训练输入：
├── 图像图 → 视觉特征编码
└── 文字图（大模型生成）
    ├── 内容描述 → 语义特征编码
    └── 情感描述 → 情感特征编码（独立特征）

融合方式：视觉特征 + 语义特征 + 情感特征 → 多模态融合
```

通过将情感单独作为特征训练，模型能够：
- 更精细地理解图像的情感表达
- 学习情感与构图质量之间的关系
- 提升对"好构图"背后情感逻辑的理解能力

### 本项目的核心贡献

1. **提示词升级**: 在原有单纯描述的基础上，增加情感描述，使大模型生成的文字图包含更丰富的情感信息
2. **情感独立特征训练**: 将情感从文本描述中单独提取，作为独立特征参与训练，使模型能够学习情感与构图质量的关系
3. **多模态情感融合架构**: 三头架构分别编码视觉特征、语义特征和情感特征，通过 Cross-Attention / Gated Fusion 实现深度融合
4. **端到端训练框架**: 完整的训练/验证/推理流程，支持多种融合策略和损失函数组合

## 技术架构

### 整体流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     数据预处理阶段                                │
│                                                                 │
│  GAIC 图像 ──→ 千问大模型 (Qwen) ──→ 情感感知提示词              │
│                  ↓                                              │
│         生成图像情感描述（温馨、宁静、热烈...）                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                     双头特征编码阶段                              │
│                                                                 │
│  ┌──────────────────────┐    ┌──────────────────────┐          │
│  │     图像头 (Visual)   │    │   情感文本头 (Text)   │          │
│  │                      │    │                      │          │
│  │  输入图像             │    │  千问生成的情感描述    │          │
│  │     ↓                │    │     ↓                │          │
│  │  CLIP 视觉编码器      │    │  CLIP 文本编码器     │          │
│  │  / ResNet-50         │    │                      │          │
│  │     ↓                │    │     ↓                │          │
│  │  视觉特征向量         │    │  情感语义特征向量     │          │
│  └──────────┬───────────┘    └──────────┬───────────┘          │
│             │                           │                       │
└─────────────┼───────────────────────────┼───────────────────────┘
              ↓                           ↓
┌─────────────────────────────────────────────────────────────────┐
│                 多模态情感融合阶段                                │
│                                                                 │
│  视觉特征 + 情感语义特征 ──→ Cross-Attention / Gated Fusion      │
│                              ↓                                  │
│                     情感-视觉融合特征                              │
│                              ↓                                  │
│                        回归预测头                                │
│                              ↓                                  │
│                    裁剪质量评分 (score)                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 关键技术组件

1. **情感描述生成**: 使用千问大模型（Qwen）+ 情感感知提示词，生成描述图像情感氛围的文本
2. **图像头**: 支持 CLIP ViT-B/32、ResNet-50 等预训练视觉编码器
3. **情感文本头**: 使用 CLIP 文本编码器将情感描述编码为情感语义特征向量
4. **多模态情感融合**: Cross-Attention / Gated Fusion / Concat 三种融合策略可选
5. **损失函数**: Smooth L1 Loss + Ranking Loss + Contrastive Loss 组合优化

#### 2. 使用千问大模型生成文本描述

使用千问大模型（Qwen）为每张图像自动生成语义描述：

```python
# 示例：使用千问大模型生成图像描述
import dashscope
from dashscope import MultiModalConversation

def generate_caption(image_path):
    """使用千问大模型为图像生成语义描述"""
    messages = [
        {
            "role": "user",
            "content": [
                {"image": image_path},
                {"text": "请描述这张图片的内容、主题、情感和构图特点。用简洁的英文描述。"}
            ]
        }
    ]
    response = MultiModalConversation.call(model='qwen-vl-max', messages=messages)
    return response.output.text

# 为数据集中的每张图像生成描述
# 保存为 captions/train.csv 和 captions/test.csv
# 格式: image_id,caption
```

生成的文本描述保存为：
```
data/GAIC/captions/
├── train.csv    # image_id,caption
└── test.csv
```

## 评估指标

1. **SRCC** (Spearman's Rank Correlation Coefficient)：预测分数与真实分数的排序相关性
2. **PCC** (Pearson's Correlation Coefficient)：线性相关性
3. **Acc@4**：Top-4 预测中包含最佳裁剪的准确率
4. **wAcc@4**：加权准确率（考虑排名位置）

## 改进方向

1. **更强的视觉编码器**：尝试 ViT-Large、DINOv2 等
2. **更精细的融合机制**：Transformer-based Cross-Attention
3. **对比学习预训练**：让模型学习好坏裁剪的差异
4. **多任务学习**：同时预测质量分数和构图类型
5. **数据增强**：随机裁剪、颜色抖动等增强策略
